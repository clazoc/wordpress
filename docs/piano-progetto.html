03

Guide — pannello WordPress ⊕ tu

Queste sono le operazioni che devi fare direttamente nel pannello WP (http://localhost:8080/wp-admin). Falle in ordine.

⚙️ 1 · Configurazione iniziale WordPress da fare ▶
1
Attiva il plugin Comparatore Core

Plugin → Plugin installati → Comparatore Core → Attiva. Questo attiva il custom post type Servizi.

2
Attiva il tema comparatore-theme

Aspetto → Temi → comparatore-theme → Attiva.

3
Imposta la homepage statica

Impostazioni → Lettura → "La tua homepage visualizza" → seleziona Una pagina statica. Per ora lascia vuoto — tornerai qui dopo aver creato le pagine.

4
Imposta il titolo del sito

Impostazioni → Generali → Titolo del sito: altrabolletta.it — Tagline: Confronta le offerte luce e gas

📄 2 · Creare le pagine e assegnare i template da fare ▶

Per ogni pagina: Pagine → Aggiungi pagina → compila titolo → nel pannello destro Attributi pagina → Template seleziona il template corretto → Pubblica.

1
Pagina Homepage

Titolo: Home · Slug: home · Template: Homepage Altrabolletta · Contenuto: lascia vuoto (il template è completamente custom)

Dopo averla creata, vai in Impostazioni → Lettura e selezionala come "Pagina iniziale".

2
Pagina Servizi (index)

Titolo: Servizi · Slug: servizi · Template: Servizi — Index · Pagina padre: nessuno

3
Pagina Servizi Privati

Titolo: Servizi per privati · Slug: privati · Template: Servizi — Privati · Pagina padre: Servizi

4
Pagina Servizi Imprese

Titolo: Servizi per le imprese · Slug: imprese · Template: Servizi — Imprese · Pagina padre: Servizi

5
Pagina Servizi Società

Titolo: Servizi per società di vendita · Slug: societa · Template: Servizi — Società · Pagina padre: Servizi

I link tra le pagine (es. dalla card "Privati" nell'index alla pagina dettaglio) funzionano automaticamente grazie alla gerarchia Servizi → Privati/Imprese/Societa.
📋 3 · Inserire i contenuti della sezione Servizi da fare ▶

Tutti i testi sono già scritti in docs/servizi-content.md — aprilo come riferimento mentre lavori nel pannello WP.

1
Vai su Servizi → Aggiungi servizio

La voce "Servizi" appare nel menu laterale del pannello dopo aver attivato il plugin.

2
Compila ogni servizio

Titolo → nome del servizio (es. "Confronto self-service")

Corpo → incolla i paragrafi dal file .md nell'editor visuale

Meta box "Dettagli servizio" (colonna destra) → Categoria, Anchor ID, Emoji, badge FREE, Prezzo, Coming soon, Oggetto email info

Attributi pagina → Ordine → il numero controlla la sequenza dei blocchi nella pagina (1 = primo)

3
Pubblica

Ogni servizio è un post separato. Puoi modificarlo, riordinarlo o archiviarlo in qualsiasi momento senza toccare il codice.

Inserisci i servizi nell'ordine corretto fin dall'inizio — l'alternanza sinistra/destra dei blocchi si basa sul numero d'ordine. Imposta Ordine: 1, 2, 3… per ogni categoria separatamente.
🧭 4 · Creare il menu di navigazione da fare ▶
1
Aspetto → Menu → Crea nuovo menu

Nome: Menu principale

2
Aggiungi le voci

Dal pannello sinistro seleziona "Pagine" e aggiungi nell'ordine:

Home · Servizi · (voci magazine/blog che aggiungerai dopo) · Chi siamo · Contatti

3
Posizione tema → Menu principale

In fondo alla pagina, spunta Menu principale sotto "Posizioni tema del display".

4
Salva il menu

Il menu apparirà nella nav della homepage e nelle pagine che usano il layout Blocksy.

📰 5 · Pubblicare articoli per il magazine ricorrente ▶

La homepage mostra automaticamente gli ultimi 3 articoli pubblicati. Non serve fare nulla di speciale — basta pubblicare post normali di WordPress.

1
Articoli → Aggiungi articolo

Scrivi titolo e contenuto nell'editor (puoi usare l'editor a blocchi Gutenberg).

2
Imposta immagine in evidenza

Nel pannello destro → "Immagine in evidenza" → carica o seleziona un'immagine. È quella che appare nella card in homepage. Dimensione consigliata: 800×500px.

3
Assegna una categoria

Crea categorie tematiche (es. "Mercato energia", "Risparmio bolletta", "Guide") per organizzare il magazine. Pannello destro → Categorie.

4
Pubblica

L'articolo appare subito in homepage (se è tra i 3 più recenti) e nell'archivio del blog.

Buona pratica SEO: compila sempre la meta description. Se hai installato Yoast SEO o RankMath, comparirà un pannello dedicato in fondo all'editor.
💻 6 · Flusso di sviluppo locale → produzione riferimento ▶

Come sincronizzare le modifiche tra sviluppo locale e ambiente di produzione.

1
Ricevere modifiche dal repo (dopo una sessione Claude Code) 
git pull origin claude/awesome-brown-ld4sm6
docker compose down && docker compose up -d
2
Salvare le tue modifiche locali 
git add .
git commit -m "Descrizione modifica"
git push origin claude/awesome-brown-ld4sm6
3
Deploy in produzione (da DEPLOY.md)

Sul server SSH nel percorso del progetto:

git pull origin main
docker compose down && docker compose up -d

Il branch di sviluppo è claude/awesome-brown-ld4sm6. Prima del deploy in produzione, fare merge su main.

Il database WordPress (contenuti, pagine, articoli) non è nel repo Git — vive solo nel volume Docker. Per migrare i contenuti da locale a produzione usa un plugin come WP Migrate o esporta/importa via wp-admin.
