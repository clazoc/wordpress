# Contenuti Servizi — Guida all'inserimento in WordPress

Dopo aver attivato il plugin **Comparatore Core**, vai su **Servizi → Aggiungi servizio** nel pannello WP.

Per ogni servizio:
1. Inserisci il **Titolo**
2. Incolla il testo nel **corpo** (editor visuale)
3. Compila la **meta box "Dettagli servizio"** nella colonna destra
4. In **Attributi pagina → Ordine** imposta il numero d'ordine (1, 2, 3…)
5. Pubblica

L'alternanza sinistra/destra è automatica in base all'ordine (primo blocco = testo a sinistra).
